# শুভ মিলন: লঞ্চ ও পরিচালনা গাইডলাইন

এই নথিতে শুভ মিলন (Shuvo Milon) প্ল্যাটফর্মের লঞ্চ প্রস্তুতি, বাজেট অ্যালার্ট এবং বিটা টেস্টিং নির্দেশিকা সংক্ষেপে লিপিবদ্ধ করা হলো।

---

## ১. রেসপনসিভ যাচাইকরণ (T8.1)
শুভ মিলন প্ল্যাটফর্মের সকল পেজ Tailwind CSS-এর মোবাইল-ফার্স্ট ডিজাইন অনুসরণ করে তৈরি:
- **মোবাইল (360px - 414px):** ড্রয়ার মেনু, বটম ন্যাভিগেশন ট্যাব (`BottomNav`), কলাপ্সিবল ফিল্টার শিট।
- **ট্যাবলেট (640px - 768px):** ২-কলাম বায়োডাটা গ্রিড ও ফর্ম সেকশন।
- **ডেস্কটপ (1024px - 1440px):** ফুল হেডার মেনু, ফিক্সড ফিল্টার সাইডবার, ৩/৪-কলাম বায়োডাটা গ্রিড।

---

## ২. ফায়ারস্টোর সিকিউরিটি রুলস যাচাই (T8.2)
- `firestore.rules` ফাইলে `users`, `profiles`, `profiles/private/contact`, `cvs`, `interests`, `matches`, `chats`, `reports`, `shortlists` কালেকশনের পূর্ণাঙ্গ অ্যাক্সেস কন্ট্রোল সংজ্ঞায়িত।
- স্থানীয়ভাবে এমুলেটর চালাতে:
  ```bash
  firebase emulators:start --only firestore
  ```

---

## ৩. পারফরম্যান্স ও লাইটহাউস (T8.3)
- নেক্সট জেএস (App Router + Turbopack) দিয়ে সকল পাবলিক ও স্ট্যাটিক পেজ অপ্টিমাইজড এসএসজি/পিপিআর ফরম্যাটে বিল্ড করা হয়েছে।
- বাংলা ফন্ট (Hind Siliguri, Noto Sans Bengali) `next/font/google` দিয়ে জিরো লেআউট শিফটে লোড হয়।
- প্রোফাইল ইমেজ থাম্বনেইল অপ্টিমাইজড।

---

## ৪. ফায়ারবেস বাজেট অ্যালার্ট সেটআপ (T8.4)
Firebase/GCP কনসোলে অপ্রত্যাশিত খরচ ঠেকাতে:
1. Google Cloud Console (`console.cloud.google.com`) এ যান।
2. **Billing** -> **Budgets & alerts** এ ক্লিক করুন।
3. নতুন বাজেট তৈরি করুন:
   - নাম: `Shuvo Milon Monthly Budget`
   - পরিমাণ: যেমন `$10` বা `$25` প্রতি মাস।
   - অ্যালার্ট থ্রেশহোল্ড: ৫০%, ৯০%, এবং ১০০% এ ইমেইল নোটিফিকেশন সেট করুন।

---

## ৫. প্রোডাকশন ডেপ্লয়মেন্ট (T8.5)
1. পরিবেশ ভেরিয়েবল সেট করুন (`.env.local` থেকে রিয়েল ফায়ারবেস ক্রেডেনশিয়ালস):
   ```bash
   npm run build
   ```
2. ফায়ারবেস হোস্টিং ও ক্লাউড ফাংশন ডেপ্লয়:
   ```bash
   firebase deploy
   ```

---

## ৬. বিটা ব্যবহারকারী টেস্টিং গাইড (T8.6)
- **উদ্দেশ্য:** প্রথম ৫০-১০০ জন বাস্তব পাত্র-পাত্রী ও অভিভাবকদের মাধ্যমে বায়োডাটা রেজিস্ট্রেশন ও ম্যাচিং ফ্লো যাচাই।
- **চেকলিস্ট:**
  1. ফোন নম্বরে ওটিপি সঠিকভাবে আসছে কিনা।
  2. বায়োডাটা ও ছবি সঠিকভাবে আপলোড এবং ব্লার টগল কাজ করছে কিনা।
  3. উভয়পক্ষের সম্মতি ও ম্যাচিংয়ের পর অভিভাবকের যোগাযোগ নম্বর দেখা যাচ্ছে কিনা।
  4. সিভি তৈরি ও পিডিএফ ডাউনলোড নির্ভুল বাংলা ফন্টে রেন্ডার হচ্ছে কিনা।
  5. কোনো অনাকাঙ্ক্ষিত বাগ বা অপব্যবহার ঘটলে রিপোর্ট সিস্টেম কাজ করছে কিনা।
