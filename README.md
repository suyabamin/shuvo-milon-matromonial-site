# শুভ মিলন (Shuvo Milon)

বাংলাদেশের বায়োডাটা-ভিত্তিক ম্যাট্রিমনিয়াল ওয়েবসাইট।

## দ্রুত শুরু
1. `docs/SETUP.md` অনুসরণ কর।
2. `npm run dev` চালাও।
3. ব্রাউজারে `http://localhost:3000` খোল।

## ডকুমেন্ট
- [AGENTS.md](./AGENTS.md): কোডিং এজেন্টের নিয়ম
- [PRD](./docs/PRD.md): পণ্যের বিবরণ
- [Features](./docs/FEATURES.md): ফিচারের তালিকা
- [Architecture](./docs/ARCHITECTURE.md): সিস্টেম ডিজাইন
- [Data Model](./docs/DATA_MODEL.md): Firestore স্ট্রাকচার
- [Design System](./docs/DESIGN_SYSTEM.md): রং, ফন্ট, কম্পোনেন্ট
- [Security](./docs/SECURITY.md): নিরাপত্তা ও প্রাইভেসি
- [Tasks](./docs/TASKS.md): কাজের তালিকা

## স্ক্রিপ্ট
| কমান্ড | কাজ |
|---|---|
| `npm run dev` | ডেভেলপমেন্ট সার্ভার |
| `npm run build` | প্রোডাকশন বিল্ড |
| `npm run lint` | লিন্ট চেক |
| `npm run test` | টেস্ট |
| `npm run emulators` | Firebase Emulator |
